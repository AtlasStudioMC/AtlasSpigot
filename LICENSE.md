# AtlasSpigot license

AtlasSpigot inherits licenses from upstream projects, plus MIT for this repo's own additions. Full
text for each license below lives in [`licenses/`](licenses/) - copied verbatim from
[Winds-Studio/Leaf](https://github.com/Winds-Studio/Leaf), since Leaf's own patches (and their
licensing) are what AtlasSpigot is built from.

| Covers | License | Full text |
|---|---|---|
| Paperweight files, most patches | MIT | [`licenses/MIT.txt`](licenses/MIT.txt) |
| Some patches, per their own header | GPL-3.0-only | [`licenses/GPL-3.0.txt`](licenses/GPL-3.0.txt) |
| Some patches, per their own header | LGPL-3.0-only | [`licenses/LGPL-3.0.txt`](licenses/LGPL-3.0.txt) |
| Some patches, per their own header | Apache-2.0 | [`licenses/Apache-2.0.txt`](licenses/Apache-2.0.txt) |
| Reference only - not currently used by any patch here | AGPL-3.0-only | [`licenses/AGPL-3.0.txt`](licenses/AGPL-3.0.txt) |
| **Compiled binaries - the released jar** | **GPL-3.0-only** | [`licenses/GPL-3.0.txt`](licenses/GPL-3.0.txt) |
| This repo's own additions ([`source-patches/`](source-patches/), configs) | MIT | [`licenses/MIT.txt`](licenses/MIT.txt) |

Certain patches are derived from other projects and retain their original licenses, as noted in
each patch's own header - check [`source-patches/`](source-patches/) and Leaf's own patch set for
specifics rather than assuming the table above is exhaustive down to the individual file.

No single license covers the whole project, which is why this repo shows as "Other" rather than a
specific license in GitHub's UI - that's accurate, not a gap. See
[Winds-Studio/Leaf](https://github.com/Winds-Studio/Leaf), [PaperMC/Paper](https://github.com/PaperMC/Paper),
and [PaperMC/paperweight](https://github.com/PaperMC/paperweight) for the authoritative licenses of
the material this project is built on.
